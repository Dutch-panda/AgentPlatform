How it works

Natasha routes your request with interactive intent alignment. Odin researches vault context and web search snippets, Taghi designs executable phases, and Meti implements, checks, and refines the deliverables through Docker. Simpler requests can start at design or implementation.

Before you run

You need Python 3.11+, Docker, and a configured model provider or compatible local endpoint. This is a local, single-user tool. Passing phase commands does not guarantee correctness; review the code and checks before relying on them.
