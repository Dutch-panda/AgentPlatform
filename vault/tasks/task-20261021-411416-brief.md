# Task: Implement a Python compound-interest calculator with pytest tests

## Assignment
- **Target Lead:** METI

## Objective
Create a simple Python script exposing a compound_interest(principal, annual_rate, years, compounds_per_year=1) function. Use A = P * (1 + r/n) ** (n*t), with annual_rate expressed as a decimal, and return the final balance. Validate that principal, annual_rate, and years are nonnegative and compounds_per_year is a positive integer; raise ValueError for invalid inputs. Include a minimal command-line interface accepting these inputs and displaying the final balance and interest earned to two decimal places, without rounding intermediate calculations. Add pytest tests for a known annual-compounding example, monthly compounding, zero principal, zero rate, zero years, and invalid inputs. Use pytest.approx for floating-point assertions. Keep implementation and tests concise, document the rate convention and usage, and provide commands to install pytest, run the script, and execute the tests.
