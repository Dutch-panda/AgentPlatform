# BuildRelay brand assets

The selected logo is **Forward B**, an angular B monogram representing BuildRelay.

Use [logo.svg](logo.svg) as the canonical asset. It has a transparent background, uses orange `#FFA064`, and scales without loss of detail. The website uses this same file for its header, footer, and favicon; the repository README displays it above the project name.

- Preserve the proportions and the negative spaces inside the B.
- Retain the built-in clear space around the mark.
- Use a dark background for the strongest contrast. Check contrast when placing it on other backgrounds.
- Use descriptive alternative text when the mark stands alone. When adjacent text already says BuildRelay, use an empty image `alt` to avoid repeating the name.

The files under `concepts/` retain the original design proposals. They are not alternative active logos. Update the canonical asset when refining the selected mark so the README and website stay consistent.
