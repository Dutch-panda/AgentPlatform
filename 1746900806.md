# Proposal: implementation delegation

Status: proposed; not implemented.

Meti currently executes phases sequentially through its Docker tool. It does not create subagents or run parallel implementation teams.

For more complex tasks, a future implementation could delegate independent work such as tests, database design, and interface implementation. Meti would then integrate the results, review the combined changes, and run validation before reporting completion.

Before implementation, define task ownership, shared-workspace coordination, failure handling, and integration checks. Existing phase validation should remain the final completion gate.
